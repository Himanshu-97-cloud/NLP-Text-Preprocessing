# 📝 NLP Text Preprocessing Pipeline

An interactive NLP preprocessing application built using **Python**, **NLTK**, and **Streamlit**.

The application allows users to apply different preprocessing operations individually or combine multiple operations to build a complete NLP preprocessing pipeline.

---

## 🚀 Features

- Convert text to lowercase
- Expand contractions
- Remove punctuation
- Remove numbers
- Remove extra spaces
- Tokenization
- Stopword removal
- Lemmatization
- Stemming
- Interactive Streamlit interface

---

## 🛠️ Technologies Used

- Python
- NLTK
- Streamlit
- Regular Expressions (re)
- Contractions

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/NLP-Text-Preprocessing.git
```

Move into the project

```bash
cd NLP-Text-Preprocessing
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
